# Telegram Video Script Bot

Telegram-бот принимает видеофайл или публичную ссылку и создаёт подробный сценарий по секундам:

- дословно распознаёт речь через OpenAI `gpt-transcribe`;
- анализирует само видео через Kie.ai Gemini 3.8 Flash;
- собирает сценарий и промпты Seedance 2.0 через Kie.ai GPT-5.6 Terra;
- определяет планы, склейки, камеру, жесты, эмоции, звук и VFX;
- принимает правки и всегда возвращает полный исправленный сценарий;
- ведёт баланс: 1 видеотокен = 1 секунда исходного видео;
- возвращает токены при технической ошибке;
- поддерживает пополнение через Telegram Stars, когда `PAYMENTS_ENABLED=true`;
- владелец с Telegram ID `780477475` работает без ограничений.

## Railway

Railway автоматически соберёт проект по `Dockerfile`. После создания сервиса:

1. Добавьте постоянный Volume, смонтированный в `/data`.
2. Создайте публичный домен Railway — он нужен Kie.ai, чтобы временно получить видео.
3. Добавьте секреты в Variables:
   - `TELEGRAM_BOT_TOKEN`
   - `OPENAI_API_KEY`
   - `KIE_API_KEY`
   - `OWNER_ID=780477475`
4. Для первого теста оставьте `PAYMENTS_ENABLED=false`.

Никогда не добавляйте реальные ключи в GitHub. Они вводятся только в защищённых Variables Railway.

## Основные команды

- `/start` — запуск и согласие на обработку;
- `/balance` — остаток видеотокенов;
- `/buy` — покупка токенов;
- `/revise текст правки` — переписать последний сценарий целиком;
- `/privacy`, `/terms`, `/support`, `/paysupport` — обязательная информация;
- `/grant TELEGRAM_ID КОЛИЧЕСТВО` — ручное начисление владельцем;
- `/stats` — статистика владельца;
- `/refund TELEGRAM_PAYMENT_CHARGE_ID` — возврат Telegram Stars владельцем.

## Ограничения MVP

- Максимальная длительность по умолчанию — 10 минут.
- Закрытые ссылки и некоторые соцсети с авторизацией могут не скачаться; тогда пользователь должен отправить файл или публичную ссылку Google Drive.
- Цены пакетов Stars настраиваются через Variables и должны быть проверены перед включением платежей.
